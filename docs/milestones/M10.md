# M10 — Evaluation framework

Implemented ten fixed scenarios, independent automated success conditions, repeated
experiments, durable per-case results and inspection APIs, CLI comparisons, source/
service/model fingerprints and optional local-only Ollama behavioral evaluations.
No paid service. SDK/HTTPX dependency decisions are in ADRs 0013/0014. Learning is
consolidated in `docs/learning/m7-m10.md`; older guides are preserved.

Sequential review: suite/oracles → typed config → atomic evaluation claim/results →
comparability → labelled HTTP contract tests → real infrastructure suite → live model
measurements. Human study has not been marked complete on the developer's behalf.

Failures found during implementation: frozen JobSpec mutation was rejected and
replaced by immutable copies; command oracle used the wrong result field and was
corrected to actual returncode. An intermittent old subprocess cleanup hang required
kill/drain/reap ordering plus a forced-backpressure regression test. Live model task
failures are recorded, never converted into fabricated infrastructure successes.

Final validation: `KAIRO_TEST_DOCKER=1 KAIRO_TEST_DATABASE_URL=<local PostgreSQL URL>
UV_CACHE_DIR=/private/tmp/kairo-uv-cache UV_OFFLINE=1 uv run --locked python scripts/check.py`
passed formatting, Ruff, strict mypy (71 source files), and **236 tests, no skips**.
Real PostgreSQL migration upgrade/downgrade/drift, actual Docker boundaries, process
termination/recovery, coordination, repeated benchmark oracles, SDK export and API
inspection all ran. Adapter unit tests use labelled HTTP fixtures; live inference
runs are separately recorded in the benchmark artifacts.

The final review corrected queued-run metadata to persist the actual injected adapter
at lease-validated worker start; a regression test verifies it. Trace operation
latencies carry logical step IDs, and evaluator summaries separate interrupted-task
completion, denied requests, detected bypasses, and scenario assertions.

Offline source/wheel build succeeded in `/private/tmp/kairo-m10-dist`; selected new
modules were byte-compared against the wheel. Benchmark execution uses the source
checkout manifest; a self-contained release installer remains M13 scope.

Earlier validated milestone commits: M7 `ac104df`, M8 `1a84d2c`, M9 `bb80ae2`.
Requested scope stops at M10. M11–M13 remain unimplemented.

Final baseline investigation: two interruption cases failed after their confirmed
append because benchmark-only expiry used host time instead of database time.
A forced +1-hour host-clock regression reproduced the empty lookup / RuntimeError
before correction. Injected expiry now uses database_now minus one second and
reports explicit ownership conflicts. Production queue lease timestamps already
used database time. Error accounting was also corrected so failed task evaluations
remain in the denominator; safe error-frame locations and a regression test were added.


Final saved experiments: four conditions × ten scenarios × two repetitions produced
80/80 passed scenario assertions on the final source fingerprint. With recovery,
2/2 interrupted tasks completed; without it 0/2 completed while the no-duplicate
append assertion still passed. No bypass occurred in the fixed permission case.
Live Ollama file/coding tasks each ran twice. Qwen single and file-multi conditions
completed 2/4 outcomes each (coding passed, file cases failed); the other installed
model completed 0/4 due to a provider HTTP rejection on continuation. An exact
no-tool replay reproduced HTTP 400 `Failed to initialize samplers: std::exception`;
a separate simple JSON request worked. These are small, contract-specific samples,
not general model rankings or statistical performance claims.

`benchmarks/results/README.md` explains portable JSON snapshots, paired comparisons,
provider diagnostics and preserved preliminary/failed evidence. Final source hashes
were verified equal across the comparable snapshots. Historical failures have distinct
fingerprints and are excluded from comparisons. No model was downloaded. No cloud
inference was used. All source modules in the final wheel were byte-verified.

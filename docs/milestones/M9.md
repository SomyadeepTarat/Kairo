# M9 — Observability and tracing

Implemented actual OpenTelemetry attempt/model/tool spans, durable correlation and
timing metadata, structured payload-free logs, failure/unfinished-span inspection,
and API/CLI trace views. The optional exporter boundary uses the standard SDK;
no hosted service or local collector is mandatory. See ADR 0013 and the shared guide.

Sequential review: Recorder decorator → event metadata → derived metrics → SDK
export/failed execution tests. Existing events remain valid, without invented spans.
Validation: full service-enabled `uv run --locked --offline python scripts/check.py`
passed formatting, Ruff, strict mypy (65 files), 224 tests, no skips. An initial
checkpoint extra-field regression caused 26 failures; envelope extraction was
corrected and the entire gate passed. No checkpoint validation was weakened.

Actual SDK export, parent correlation, errors, cancellation, incomplete durable
prefix and API diagnostics passed against real PostgreSQL. Fresh CLI history run
`97b06390-cb70-49b5-92e6-c76aac428d9c` completed real file write/read and persisted
25 events. Trace CLI verified six finished spans and no incomplete operations.
No provider token counts or host resource measurements were fabricated.
